# 🔎 Overview

**AI Video Evidence Authentication** is a multimodal forensic AI platform designed to analyze digital video evidence and determine whether media is **authentic/original or tampered/manipulated**.

The platform brings together multiple layers of computational analysis into a unified forensic workflow:

<table>
<tr>
<td width="50%">

### 🎥 Video Intelligence

* Frame extraction
* Face analysis
* Visual artifact analysis
* Deepfake detection
* Multiple vision architectures
* Temporal reasoning

# 🔗 Blockchain Evidence Integrity

Blockchain is used as an **evidence integrity layer**, not as an AI authenticity detector.

```text
                    ORIGINAL MEDIA
                          │
                          ▼
                  ┌───────────────┐
                  │    SHA-256    │
                  │ Cryptographic │
                  │     Hash      │
                  └───────┬───────┘
                          │
                          ▼
                  ┌───────────────┐
                  │ Evidence ID   │
                  │ Timestamp     │
                  │ Hash Reference│
                  └───────┬───────┘
                          │
                          ▼
                  ┌───────────────┐
                  │  BLOCKCHAIN   │
                  │    RECORD     │
                  └───────┬───────┘
                          │
                          ▼
                  ┌───────────────┐
                  │ Verification  │
                  └───────────────┘
```

> **Important:** Blockchain integrity and media authenticity are separate concepts. A blockchain record can help verify that a referenced artifact has not changed, but it does not by itself establish that the underlying content is authentic.

# 🧪 Evaluation Framework

TrustVision is designed to evaluate forensic models using multiple quantitative dimensions.

<div align="center">

|           Metric          | Purpose                            |
| :-----------------------: | :--------------------------------- |
|        **Accuracy**       | Overall classification correctness |
|       **Precision**       | Positive prediction reliability    |
|         **Recall**        | Detection coverage                 |
|        **F1-Score**       | Precision–recall balance           |
|        **ROC-AUC**        | Class discrimination               |
|    **Confusion Matrix**   | Error distribution                 |
| **Temporal Localization** | Suspicious segment detection       |
|   **Inference Latency**   | End-to-end processing performance  |
|   **Blockchain Latency**  | Evidence registration performance  |

# ⚡ Quick Start

## 1️⃣ Clone

```bash
git clone https://github.com/PrajwalM-2345/AI-Video-Evidence-Authentication.git

cd AI-Video-Evidence-Authentication
```

## 2️⃣ Create Virtual Environment

```bash
python3.11 -m venv .venv

source .venv/bin/activate
```

### Windows

```powershell
.venv\Scripts\activate
```

## 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

## 4️⃣ Train

```bash
python train.py
```

## 5️⃣ Start Backend

```bash
uvicorn backend.main:app --reload
```

## 6️⃣ Start Frontend

```bash
cd frontend

npm install

npm run dev
```
